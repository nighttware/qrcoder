QR Coder

100% free open-source application for fast and simple QR code generation. Available for Desktop and Web.

View on GitHub  

Manual Generation

Type a URL, IP, or intranet path and preview the QR code in real time.

Bulk Import

Drag or select a CSV with Link and Caption columns to generate several QR codes at once.

Downloads

Download your results individually as high-quality PNGs (300 dpi) or in bulk as a ZIP archive.
